# BCI research

This repository contains software and experiment resources for brain-computer
interface (BCI) research. It supports controlled EEG data collection,
imagined-speech experiments, steady-state visual evoked potential (SSVEP)
experiments, and validation of stimulus timing and display frequencies.

## Projects

- [imagined-speech-psychopy](imagined-speech-psychopy/) — EEG recording and
  PsychoPy presentation for imagined-speech experiments.
- [ssvep-bci](ssvep-bci/) — configuration-driven SSVEP presentation, EEG
  acquisition, session recording, and live processing.
- [ssvep-frequency-test](ssvep-frequency-test/) — Arduino photosensor
  recording and analysis for validating SSVEP stimulus frequencies and timing.
